# Volunteer Disaster Relief Coordination System

##  Overview

A web-based system for managing and coordinating volunteers, relief tasks, affected areas, and resources during disasters such as floods, cyclones, and earthquakes.

##  Users

* **Admin** – Manages disasters, volunteers, tasks, resources, and reports.
* **Volunteer** – Registers, accepts relief tasks, updates progress, and sends SOS alerts.
* **Relief Coordinator** – Monitors affected areas, volunteers, resources, and relief activities.

##  Key Features

* User Registration & Role-Based Login
* Disaster Management
* Affected Area Management
* Relief Task Management
* Volunteer-Task Matching
* Task Status Tracking
* Resource Management
* Disaster Priority Scoring
* SOS Alerts
* Volunteer Workload Balancing
* Notifications & Reports

##  Tech Stack

* **Frontend:** HTML, CSS, JavaScript / React
* **Backend:** Java Spring Boot
* **Database:** MySQL
* **Authentication:** JWT
* **API:** REST API
* **Version Control:** Git & GitHub

##  Goal

To improve disaster relief coordination by assigning suitable volunteers, prioritizing affected areas, tracking relief tasks, and managing resources efficiently.

##  Future Scope

* AI-based Volunteer Recommendation
* AI-based Demand Prediction
* IoT Disaster Monitoring
* GPS Location Tracking
* Predictive Resource Allocation

##  Limitations

The system does not provide direct medical treatment, physical rescue operations, or replace official government emergency response systems.
